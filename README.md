# Balaji Group - Contractor Rewards Program

Web and Android apps for the Balaji Group contractor rewards program. Branch staff record members, bills, and trip eligibility. Admins review results across branches.

## Project structure

| Folder | Description |
| --- | --- |
| `backend/` | Express API with SQLite storage (`node:sqlite`). Serves the branch app and admin panel. |
| `branch-app/` | Branch staff app built with React and Vite. Packaged for Android with Capacitor. |
| `admin-web/` | Admin panel built with React, Vite, and Tailwind CSS. |
| `render.yaml` | Render deployment blueprint for the backend. |

## Requirements

- Node.js 22.13.0 or later (for `node:sqlite`)
- Android Studio (only for building the Android app)

## Backend

```bash
cd backend
npm ci
npm run seed    # creates branches and accounts; passwords are printed once
npm start       # http://localhost:3000
npm test
```

Environment variables:

| Variable | Default | Purpose |
| --- | --- | --- |
| `PORT` | `3000` | HTTP port |
| `DB_FILE` | `backend/data/balaji.db` | SQLite database file |
| `CORS_ORIGINS` | `https://localhost` | Comma-separated list of allowed origins |

`npm run seed` only creates accounts that do not exist yet. To start with a fresh set of passwords, point `DB_FILE` at a new file.

The API exposes `GET /api/health` for health checks.

## Branch app

```bash
cd branch-app
npm ci
npm run dev     # http://localhost:5173, proxies /api to http://localhost:3000
npm run build
```

Set `API_URL` to point the dev proxy at a different backend, for example `API_URL=http://localhost:3001`.

To build the Android app:

```bash
cd branch-app
npm run build
npx cap sync android
npx cap open android
```

Each branch account only sees its own branch. The branch is set by the account and cannot be changed in the app.

## Admin web

```bash
cd admin-web
npm ci
npm run dev     # http://localhost:5174, proxies /api to http://localhost:3000
npm run build
```

## Deployment

`render.yaml` defines a Render web service for the backend. It uses `backend/` as the root, runs `npm ci` to build and `npm start` to run, and stores the SQLite database on a persistent disk at `/var/data`.

## Security notes

- Passwords are hashed with scrypt.
- Login attempts are rate limited.
- Do not commit `.db` files, `.env` files, or the credentials generated by the seed script. They are listed in `.gitignore`.
